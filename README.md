# From AI Strategy to University Rules in the GCC

This public repository supports the ICAMAC 2026 paper **“From AI Strategy to University Rules in the GCC.”**

## What the archive preserves and derives
The documentary classifications are locked analytical inputs. The archive preserves those classifications and reproducibly derives:
- six-jurisdiction L1->L4 numerical summaries and robustness diagnostics;
- corrected 58-institution deterministic-panel counts and jurisdiction/stratum summaries;
- equal-cell and oldest-three sensitivities;
- interval-valued fuzzy representation envelopes;
- broader UAE OBEF L3 sensitivity;
- manuscript Fig. 1; and
- a repository-only auxiliary institutional-panel visualization (`Auxiliary_58_Institution_Stratified_Audit.png`).

It also provides selected-HEI eligibility certificates, jurisdictional official-registry sources, the retrospective eligibility-boundary audit, and the documented `U` search stopping rule.

Run `bash run.sh`. Internet access is not required for numerical reproduction. URLs in the data files are provenance locators, not computational dependencies.

## Selection-universe boundary
The complete pre-outcome eligible universe beyond the original oldest-four boundary was not preserved before AI-policy outcomes were known. The archive therefore does **not** present a retrospectively assembled web list as the original pre-outcome universe. Instead it provides official-source certificates for all 58 selected institutions and known boundary cases. A retrospective full-frame completeness audit is being maintained separately and must not be described as the original frozen sampling frame. Oldest-five is not reported.

## Claim boundary
The package preserves documentary classifications and derives numerical outputs from them. It does not establish implementation quality, sector prevalence, country ranking, causal policy translation, or absence of non-public institutional rules. `U` means that qualifying public evidence was not located under the documented protocol by the cutoff.
