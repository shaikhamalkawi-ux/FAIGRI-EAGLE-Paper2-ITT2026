# Camera-ready repository insertion text

Do **not** insert a public author-identifying GitHub link into the double-blind manuscript.

After double-blind review has ended and the final GitHub repository is ready for public release, a camera-ready availability statement can use wording such as:

> The accompanying reproducibility archive preserves the locked documentary classifications and provides the data tables, provenance records, eligibility-audit files, documented search records, code, and derived outputs needed to reproduce the reported numerical summaries, sensitivities, and figures. The maintained archive is available at [GitHub URL].

Replace the bracketed placeholder only after the repository is made public and the final release state is confirmed.

No Zenodo DOI is used at the current stage.
