# Zenodo upload guide - RELEASE HOLD

Do not deposit/publish this release candidate while double-blind review is active if the resulting public record would reveal author identity.

Before publication:
1. confirm the review stage permits an author-identifying public archive;
2. choose the formal license(s) for author-created code/data/documentation;
3. confirm the final author names/order and metadata;
4. if linking GitHub, create the final GitHub release first;
5. upload this cleaned package to Zenodo and obtain the DOI;
6. insert the DOI/URL only in the non-anonymous camera-ready manuscript;
7. regenerate release hashes after any metadata or file change.

Third-party source documents are not redistributed; their official URLs remain provenance locators.
